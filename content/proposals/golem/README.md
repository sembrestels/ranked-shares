# Golem ecosystem proposals

Proposals from the community to the Golem ecosystem, for a RankedShares round
sponsored by a Golem treasury where seats go to GLM/ETH Uniswap v4 liquidity
providers. One `.md` file per proposal, filename is the slug, `goal` in USDC (a plain number of dollars).

```markdown
---
title: golem-js examples and tutorials refresh
type: grant
goal: 12000
currency: USDC
summary: One-paragraph card text.
duration: 4
---
Body: why it matters, what gets done, milestones as - [ ] checklists with an
amount per milestone that sums to the goal.
```
