# Urbe Hub proposals

One `.md` file per proposal. The filename is the permanent slug. Goals are
denominated in EURC (euro stablecoin); `goal` is a plain number of euros.

```markdown
---
title: 3D printing station
type: grant
goal: 1400
currency: EURC
summary: One-paragraph card text.
duration: 3
---
Body in markdown: why it matters, what gets bought or done, milestones as
- [ ] checklists with an amount per milestone that sums to the goal.
```
